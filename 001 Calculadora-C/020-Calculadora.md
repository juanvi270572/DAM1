🧮 Calculadora de IVA

Versión: 0.2
Autor: Juan Vicente Gallart

📋 Descripción

Calculadora desarrollada en lenguaje C para practicar programación y facilitar el cálculo del IVA sobre una cantidad económica.

Este proyecto forma parte de mi aprendizaje en el ciclo de Desarrollo de Aplicaciones Multiplataforma (DAM).

✨ Características

  💶 Cálculo del IVA de una cantidad.

  🧾 Obtención del importe del IVA.

  💰 Cálculo del precio final con IVA incluido.

  💻 Interacción mediante consola.

  🛠️ Compilación con GCC.

  🛠️ Tecnologías utilizadas

Lenguaje: C

Compilador: GCC

Editor: Visual Studio Code

Sistema operativo: Windows

🚀 Compilación y ejecución

Para compilar el programa, abre una terminal en la carpeta donde se encuentra el código fuente y ejecuta:

gcc 020-Calculadora.c -o calculadora.exe

A continuación, ejecuta la calculadora desde PowerShell:

.\calculadora.exe

📚 Objetivo del proyecto

Practicar los fundamentos de la programación en C, mejorar la lógica de programación y familiarizarme con la compilación y ejecución de programas.

Este proyecto podrá evolucionar con nuevas funcionalidades y mejoras en futuras versiones.
